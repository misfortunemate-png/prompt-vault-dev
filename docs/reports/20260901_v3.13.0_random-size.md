## 実装内容

`src/screens/GenerateScreen.jsx` のみ変更（フロント完結）。

### フロー調査結果

フロントエンドが `width/height` を決定して API に渡している（fran: POST /api/generate、cloud: Worker POST /api/prompt-vault/generate）。DO側・server側への変更は不要。

### 変更箇所

1. **state追加**: `const [randomSize, setRandomSize] = useState(false)`

2. **ヘルパー関数追加**:
   ```javascript
   const pickResolution = () => randomSize
     ? RESOLUTIONS[Math.floor(Math.random() * RESOLUTIONS.length)]
     : (RESOLUTIONS.find(r => r.value === resolution) || RESOLUTIONS[0]);
   ```
   - RESOLUTIONS配列（縦/横/正方）は既存の定数をそのまま利用

3. **handleGenerate()**: `res = pickResolution()` に変更

4. **buildSingleTask()**: `res = pickResolution()` に変更

5. **buildCartesianTasks()**: `params` を per-task 生成に変更
   - 直積の各タスクが独立してランダムサイズを持つ

6. **UI**: 解像度セレクトの下にチェックボックス追加
   - ON時: セレクトを `disabled` + `opacity: 0.5` で視覚的に無効化
   - OFF時: 既存動作（セレクトで固定値を選択）
