## 1. 実装内容の要約

### server/db.js（更新）

- `listByFolder` / `getRecent`: SELECT に `favorite` カラムを追加
- `setFavorite(hash, flag)`: `UPDATE images SET favorite = ? WHERE hash = ?`
- `getFavorites(limit)`: `WHERE favorite = 1 ORDER BY created_at DESC LIMIT ?`
- `search(query, limit)`: prompt/negative/folder/filename/caption に対する OR LIKE 検索
- `getByPreset(presetId, limit)`: `WHERE preset_id = ? ORDER BY created_at DESC LIMIT ?`
- `setCaption(hash, text)`: `UPDATE images SET caption = ? WHERE hash = ?`

### server.js（更新）

5エンドポイント追加（thumbUrl マッピング含む）:
- `PUT /api/gallery/image/:hash/favorite` — body `{ favorite: 0|1 }`
- `GET /api/gallery/favorites?limit=50`
- `GET /api/gallery/search?q=&limit=50`
- `GET /api/gallery/by-preset/:presetId?limit=50`
- `PUT /api/gallery/image/:hash/caption` — body `{ caption: "..." }`

### src/lib/api.js（更新）

`setFavorite` / `getFavorites` / `searchGallery` / `getByPreset` / `setCaption` を追加。

### src/components/ImageViewer.jsx（新規）

Props: `images`, `initialIndex`, `onClose`, `onFavoriteToggle`, `onCaptionSave`

- **スワイプ**: `touchstart/end` で dx/dy 計測。横50px以上で前後、上80px以上で閉じる
- **タップ**: 左1/4で前、右1/4で次、中央でオーバーレイ展開/折りたたみ
- **ピンチズーム**: 2点タッチで距離比から scale 変化（0.5〜5倍）。ダブルタップでリセット
- **×ボタン**: 右上に常時表示
- **情報オーバーレイ**: 折りたたみバー（ファイル名＋★）。展開でメタデータ・プロンプト（3行切り捨て）・ネガティブ・セリフ表示/編集
- **★お気に入り**: PUT API 呼び出し → `favoriteMap` state 更新 → `onFavoriteToggle` コールバック
- **セリフ編集**: タップ → textarea 展開 → 保存ボタンで PUT API
- **横向き**: CSS `@media (orientation: landscape)` で外コンテナを row 方向に変更、オーバーレイを右サイドパネル化

### src/screens/AlbumScreen.jsx（更新）

- インラインビューアを削除し `<ImageViewer>` コンポーネントに委譲
- `flatMode` state: `null | { type, label, images }` でお気に入り・検索・プリセット別を統一管理
- **ヘッダー**: ★（お気に入りフィルタ）・🔍（検索バー展開）・🔄（リスキャン）
- **検索バー**: 展開時にテキスト入力表示。Enter or 送信ボタンで `searchGallery` 呼び出し
- **ルート表示**: 新着 → プリセット別チップ（水平スクロール）→ フォルダ（☰/▦ トグル）
- **フラット表示**: お気に入り・検索結果・プリセット別。3列グリッド。検索・プリセット結果は左下にフォルダ名バッジ
- **ThumbCell**: `isFavorite` で右上に★オーバーレイ、`showFolder` でフォルダ名バッジ
- **favUpdates**: ビューアで変更したお気に入りをセッション内で追跡。リロード不要
