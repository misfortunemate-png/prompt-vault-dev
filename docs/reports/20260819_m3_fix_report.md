## 1. 実装内容の要約

**GenerateScreen.jsx**  
各スロット行のレイアウトを2段構成に変更：
- 管理行: `[▲][▼] [スロット名] [F☐] [N☐] [×]`
- カード選択行: `[カード選択プルダウン ─────] [✏️]`

追加した操作:
- `▲▼` ボタン: PUT /api/cards でorderを入れ替えてソート順を変更
- `F☐ N☐` チェックボックス: PUT /api/cards/slot/:id で即時反映
- `×` ボタン: 確認ダイアログ → DELETE /api/cards/slot/:id
- `＋ スロット追加` ボタン: window.prompt → POST /api/cards/slot

各操作後に `refreshCardsData()` を呼んで画面を即時更新する。三点リーダ（⋯）メニューは除去。  
VAULT_ROOT未設定時もスロット管理UIは表示する（cardsDataはVAULT_ROOT不要で取得可能）。

**TemplateCardList.jsx**  
スロット一覧を簡素化：
- ドラッグハンドル（☰）・パス設定（F/N）・削除ボタン・⋯メニューをすべて除去
- 各行: スロット名（タップでカード一覧へ）+ 枚数 + 改名ボタン（✎）のみ
- スロット追加ボタンは維持（テンプレートタブでもスロット追加可能）
