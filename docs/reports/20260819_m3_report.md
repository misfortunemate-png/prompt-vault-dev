## 1. 実装内容の要約

v3.3.0（M3: カードシステム）として以下を実装した。

**サーバー側（server.js）**
- `data/cards.json` / `data/presets.json` の起動時自動生成（初期5スロット・カード0件）
- スロット CRUD: `POST/PUT/DELETE /api/cards/slot/:id`
- カード CRUD: `POST/PUT/DELETE /api/cards/card/:id`・複製: `POST /api/cards/card/:id/duplicate`
- プリセット CRUD: `POST/PUT/DELETE /api/presets/:id`・複製・タグ一覧 `GET /api/presets/tags`
- `GET /api/tags/search?q=` — danbooru-filtered.csv をメモリ読み込み・前方一致・最大20件
- `POST /api/save` を M3形式（folderSegments/filenameSegments/seed）に更新
- M2マイグレーション: 起動時に `VAULT_ROOT/presets.json` があり `data/cards.json` がない場合に自動変換・.bak化

**フロントエンド**
- `src/screens/TemplateScreen.jsx` — サブナビ（カード/プリセット）付きコンテナ
- `src/screens/TemplateCardList.jsx` — スロット一覧（ドラッグ並替・F/Nチェックボックス・CRUD）→ カード一覧 → カード編集の3階層ナビ
- `src/screens/TemplateCardEdit.jsx` — TagSuggest付きカード編集フォーム
- `src/screens/TemplatePresetList.jsx` — タグフィルタ付きプリセット一覧・CRUD
- `src/screens/TemplatePresetEdit.jsx` — TagInput/スロット別カード選択/合成プレビュー/保存先プレビュー
- `src/components/TagSuggest.jsx` — カンマ区切りトークン補完（debounce 300ms・キーボードナビ）
- `src/components/TagInput.jsx` — チップ方式タグ入力
- `src/screens/GenerateScreen.jsx` — 動的スロットプルダウン・インラインカード編集（上書き/新規）・M3形式保存
- `src/components/Toast.jsx` — success/info 10秒後 CSS フェードアウト（error は手動消去のまま）
- `src/App.jsx` — テンプレートタブを `PlaceholderView` から `TemplateScreen` に切替

**インフラ**
- `scripts/inspect.mjs` — danbooru-filtered.csv の SHA-256 照合チェックを追加
- `package.json` — 3.2.0 → 3.3.0
- `CLAUDE.md` — M3 API一覧・データファイル・テンプレートタブの説明を追記
- `_STATUS.md` — M3完了に更新（28行）

## 7. マイグレーションテストの結果

コード実装のみで実機検証は未実施（VAULT_ROOT環境なし）。変換ロジックの概要:

**変換前（VAULT_ROOT/presets.json / M2形式）想定例:**
```json
{
  "presets": [{"name":"ポートレート","positive":"portrait, ...","negative":"lowres"}],
  "characters": ["キャラA","キャラB"],
  "outfits": ["制服","私服"],
  "situations": ["室内","屋外"],
  "extras": ["笑顔"]
}
```

**変換後（data/cards.json）:**
- スロット5件（初期生成）: キャラクター/衣装/シチュエーション/構図・品質/自由
- characters → キャラクタースロットのカードとして追加
- outfits → 衣装スロットのカードとして追加
- situations → シチュエーションスロットのカードとして追加
- extras → 自由スロットのカードとして追加
- presets[].positive/negative → 構図・品質スロットのカードとして追加
- `VAULT_ROOT/presets.json` → `VAULT_ROOT/presets.json.bak` にリネーム

**冪等性:** 2回目起動時は `data/cards.json` が既存のためマイグレーションをスキップ。
