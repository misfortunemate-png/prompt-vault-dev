作成日: 2026-08-20 / 実装: Claude

## 各項目の実装要約

### #1 ビューア速度改善（`src/components/ImageViewer.jsx`）

**サムネイル先行表示**: 画像表示切り替え時に `displaySrc` を `/api/thumbs/{hash}.webp` に設定し、`opacity:0.5 + filter:blur(6px)` で表示。バックグラウンドで `new Image()` により原寸ロード完了後、差し替え + blur解除。

**前後プリロード**: `useEffect([idx, images])` にて `images[idx-1]` と `images[idx+1]` を `new Image().src` でブラウザキャッシュに投入。

### #2 台詞の画面表示（複数ファイル）

- `server/db.js`: `ALTER TABLE images ADD COLUMN caption_config TEXT`（try/catch で既存DB互換）、`setCaptionConfig()`・`getGalleryByCard()`・`getTotalByCard()` ヘルパー追加
- `server.js`: `PUT /api/gallery/image/:hash/caption` を拡張（`captionConfig` も保存）、`GET /api/gallery/by-card` 新設
- `src/lib/api.js`: `setCaption` を `captionConfig` 引数対応に更新、`getGalleryByCard` 追加
- `src/components/ImageViewer.jsx`: 台詞レンダリング実装
  - **余白モード（既定）**: portrait → flex-row、右に `writing-mode: vertical-rl`；landscape → flex-column、下に横書き
  - **画像内モード**: `position: absolute` で `left: {x}%; top: {y}%` + `transform: translate(-50%,-50%)`
  - タップで位置設定（`onClick` + `onTouchEnd`）、マウスドラッグで微調整
  - スタイル設定UI: モード切替・フォントサイズ（小/中/大）・色（3色プリセット＋カスタム）・縁取り
- `src/screens/SettingsScreen.jsx`: `captionStyle` state追加、設定読込/保存、台詞表示セクション追加
- `data/settings.json` `DEFAULT_SETTINGS`: `captionStyle` フィールド追加

### #3 カード一覧リデザイン（`src/screens/TemplateCardList.jsx`）

⋯ContextMenu を完全廃止。カード行を以下レイアウトに刷新:
- 左: 2×2 サムネイルグリッド（各42px）
- 中: カード名（太字）→ 正プロンプト（グレー・2行clamp）→ 負プロンプト（赤系・2行clamp）
- 右: 編集/コピー/削除 直接ボタン＋採用枚数

**サムネイル取得方式（選択: prompt LIKE 検索）**: カードの positive テキスト先頭100文字で `prompt LIKE '%...%'` 検索。既存画像に遡及適用可能で、スキーマ変更不要のため採用。`total` フィールドで採用枚数も返す。

### #4 プリセット一覧リデザイン（`src/screens/TemplatePresetList.jsx`）

⋯ContextMenu 完全廃止。プリセット行を以下レイアウトに刷新:
- 左: 2×2 サムネイルグリッド（`getByPreset` 既存API使用）
- 中: プリセット名 → タグチップ → スロット割当（`スロット名:カード名` スラッシュ区切り）→ 保存先パスプレビュー（monospace）
- 右: 編集/コピー/削除 直接ボタン

パスプレビューは preset の `folder`/`filename` フィールド（ない場合は slots の F/N から計算）を使用。

### #5 プリセット編集画面リデザイン（`src/screens/TemplatePresetEdit.jsx`）

ローカル state:
- `slotOrder`: スロットIDの配列（▲▼で並び替え）
- `slotFolder`: F フラグのスロットID（1つのみ、checkbox で toggle、再クリックで null）
- `slotFilename`: N フラグのスロットIDの配列

スロット行: `[▲▼] [スロット名] [カードプルダウン] [F☐] [N☐]`

合成プロンプトプレビュー・保存先プレビューはリアルタイム更新。保存時に `{ name, tags, cards, slotOrder, folder, filename }` を送信。

### #6 プリセットにスロット構成を保存（`src/screens/GenerateScreen.jsx`）

`localSlotOrder`（null or slotId[]）と `localSlotProps`（slotId → {useAsFolder, useInFilename}）state を追加。

`sortedSlots` 計算を更新:
- `localSlotOrder` があればそれで並べ替え、なければ `slot.order` でソート
- 各スロットの `useAsFolder`/`useInFilename` は `localSlotProps` があれば上書き

`handlePresetSelect`: preset.slotOrder → localSlotOrder に設定、preset.folder/filename → localSlotProps に展開。後方互換: フィールドがなければ localSlotProps は空のまま。

### #7 F排他制御

**生成画面** `handleToggleSlotProp`: `useAsFolder` の場合、`api.putCards` で全スロットに適用（全 useAsFolder を false にしてから対象のみ true に設定）。N は従来通り `api.updateSlot` で個別更新。

**プリセット編集画面** `toggleFolder`: `slotFolder` は単一値のため、再クリックで null にする toggle。同一名がセットされることは構造的にない（単一値 state）。
