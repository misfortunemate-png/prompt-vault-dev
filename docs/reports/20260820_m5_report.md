## 実装内容

### server/generate.js（新規）

- `executeGenerate({...})`: novelai APIを呼び出し `.tmp/` に保存
- `executeSave(vaultRoot, {...})`: tmpからVAULT_ROOTへ移動・DB登録・サムネイル生成
- server.js の POST /generate と POST /save がこれを利用（コード共有、コピーなし）

### server/queue.js（新規）

- インメモリ状態 `q`（idle/running/paused）
- タスクステータス: pending → running → done / error → skipped
- `addTasks()`: maxPerJob ガードチェック付き
- `startQueue(vaultRoot)`: `setImmediate()` で非同期ループ開始
- `runLoop()`: タスクを直列実行、タスク間ランダム間隔待機（intervalMin〜intervalMax秒）
- エラー発生時: 後続 pending タスクを skipped に変更し state=paused で停止
- `stopQueue()`: `_stopRequested` フラグで現在タスク完了後に中断

### GenerateScreen.jsx UI

- **生成ボタン行**: 「生成」（flex:2）| 「＋キュー」（flex:1）| 「＋直積」（flex:1）
- **キューパネル**（折りたたみ式）:
  - ヘッダー: タスク件数・進捗バー・実行中/中断ステータス
  - タスク一覧: ステータスアイコン・ラベル・pending時×削除ボタン
  - 実行情報: 現在タスク名・経過時間・残り推定（平均から算出）
  - 操作ボタン: ▶実行 / ⏸中断 / 🗑クリア
- **直積ダイアログ**:
  - スロットごとに「固定」/「全展開」切替ボタン
  - 件数プレビュー（`1 × 4 × 1 = 4件` 形式）
  - 「キューに追加」/「キャンセル」ボタン
