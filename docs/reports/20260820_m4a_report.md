## 1. 実装内容の要約

### server/db.js（新規）
- `better-sqlite3` で `data/index.db` を初期化（WALモード）
- §2.1 のCREATE TABLE / CREATE INDEX を自動実行
- エクスポート: `getByHash`, `upsertImage`, `deleteByHash`, `listByFolder`, `listFolders`, `getRecent`, `getStats`, `setThumbOk`, `getAllHashes`

### server/png-meta.js（新規）
- PNGバイナリから `tEXt` / `iTXt` チャンクをスキャン
- NovelAI形式（`Comment` JSON・`Description` テキスト）をパース
- 失敗時はすべてNULLで返す（エラーにしない）
- 外部ライブラリ不使用

### server/scanner.js（新規）
- `startScan(vaultRoot)`: VAULT_ROOT再帰走査 → SHA-256先頭16文字 → DB照合 → INSERT/UPDATE/DELETE
- `.tmp/` ディレクトリは走査スキップ
- `generateThumb(hash, srcPath)`: sharp で長辺300px WebP品質80 → `data/thumbs/{hash}.webp`、生成後 `thumb_ok = 1`
- 進捗状態: `{ scanning, total, processed, newCount, movedCount, deletedCount }`
- `getScanStatus()` エクスポート

### server.js（更新）
- インポート追加: `createHash`, db helpers, scanner, parsePngMeta
- `THUMBS_DIR` 定数追加
- `initVaultStructure()`: VAULT_ROOT設定時に `setImmediate(() => startScan(vaultRoot))` で起動時スキャン
- ギャラリーAPI: `GET /api/gallery`（フォルダツリー）, `/api/gallery/folder`, `/api/gallery/recent`, `/api/gallery/image/:hash`, `/api/gallery/stats`
- サムネイルAPI: `GET /api/thumbs/:hash.webp`（Cache-Control: public, max-age=86400）
- 原寸API: `GET /api/images/full/:hash`（ハッシュ→rel_path→sendFile）
- リスキャンAPI: `POST /api/rescan`, `GET /api/rescan/status`
- `POST /api/save`: renameSync後に `readFileSync` → hash計算 → `upsertImage` → 非同期サムネイル生成

### src/screens/AlbumScreen.jsx（全面書き直し）
- ヘッダー行: パンくず（ルート > フォルダ名 > ...、各ノードタップで上位遷移）+ 🔄リスキャンボタン + 進捗表示
- ルート表示: 新着20枚（3列グリッド）+ フォルダツリー（再帰FolderRowコンポーネント）
- フォルダ表示: サブフォルダ行 + 3列サムネイルグリッド（正方形クロップ）
- サムネイル未生成時: グレーボックス + ⟳プレースホルダー
- ビューア: 4象限タップナビ維持（左上=閉じる、右上=次、左下=前、右下=次）、原寸URLは `/api/images/full/:hash`
- リスキャンUI: 🔄タップ → POST /api/rescan → 3秒ポーリング → トースト通知 → 画面リフレッシュ
