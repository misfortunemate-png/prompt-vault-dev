# Prompt Vault M4-B 仕様書 v1.0

文書種別: 権威文書
作成日: 2026-08-20 ／ PM: クリーデ ／ 根拠: 要件定義v1.3 R-4（閲覧・整理）・R-5（セリフ表示）

## §1 スコープ

M4-Bはギャラリー本装のUI層。M4-Aで構築したSQLiteインデックスの上に、ビューア本装・お気に入り・検索・プリセット別アルバム・セリフ表示を実装する。

- In: ビューア（スワイプ・前後ボタン・横向き対応）、お気に入り、検索（プロンプト・フォルダ）、プリセット別アルバム、セリフ表示・編集
- Out: オフライン持ち出し（M7）、ファイル移動・リネーム・削除（将来工事）

## §2 ビューア本装

M4-Aの4象限タップビューアを、独立コンポーネント `ImageViewer.jsx` に分離し本装する。

### §2.1 基本操作

| 操作 | 動作 |
|---|---|
| 左スワイプ | 次の画像 |
| 右スワイプ | 前の画像 |
| 画面左端タップ | 前の画像 |
| 画面右端タップ | 次の画像 |
| 上スワイプ or ×ボタン | ビューア閉じる |
| ピンチ | ズームイン/アウト（CSS transformで実装） |

- 先頭/末尾で前/次 → 何もしない（ループしない）
- スワイプ検出: `touchstart`/`touchmove`/`touchend` でdx/dy計測。横方向50px以上で発火

### §2.2 情報オーバーレイ

画像下部に半透明バーで以下を表示。タップで展開/折りたたみ。

- ファイル名、フォルダ、生成日時
- プロンプト（正・負）。長い場合は3行で切り捨て、展開で全文
- seed、model、steps、scale、sampler
- お気に入りボタン（§3）
- セリフ表示エリア（§6）

### §2.3 横向き対応

`orientation: landscape` メディアクエリで、情報オーバーレイを画像の右サイドに配置（画像を横幅いっぱいに表示するため）。

### §2.4 ×閉じるボタン

右上に常時表示の×ボタン。タップでビューア閉じる。

## §3 お気に入り

### §3.1 フラグ操作

- ビューアの情報オーバーレイに ☆/★ ボタン。タップでトグル（`PUT /api/gallery/image/:hash/favorite`）
- サムネイルグリッドのセルにも小さな★アイコンをオーバーレイ（お気に入り画像のみ）

### §3.2 お気に入りフィルタ

アルバムタブのヘッダー行に★フィルタボタン。ON時はお気に入り画像のみ表示（フォルダ構造を無視してフラットなサムネイルグリッド）。

### §3.3 API

| メソッド | パス | 用途 |
|---|---|---|
| PUT | /api/gallery/image/:hash/favorite | お気に入りトグル。body: `{ favorite: 0|1 }` |
| GET | /api/gallery/favorites?limit={n} | お気に入り画像一覧（既定50件・created_at降順） |

## §4 検索

### §4.1 検索UI

アルバムタブのヘッダー行に🔍ボタン。タップで検索バーを展開。テキスト入力＋Enterで検索実行。

### §4.2 検索対象

SQLiteの `images` テーブルに対するLIKE検索:
- `prompt` カラム（正プロンプト）
- `negative` カラム（負プロンプト）
- `folder` カラム（フォルダ名）
- `filename` カラム（ファイル名）
- `caption` カラム（セリフ）

ORで結合（いずれかにヒットすれば表示）。

### §4.3 検索結果

フォルダ構造を無視してフラットなサムネイルグリッドで表示。各サムネイルにフォルダ名ラベルを小さく重ねる（どこの画像かわかるように）。

### §4.4 API

| メソッド | パス | 用途 |
|---|---|---|
| GET | /api/gallery/search?q={query}&limit={n} | テキスト検索（既定50件） |

## §5 プリセット別アルバム

### §5.1 表示

アルバムタブのフォルダセクションの上（新着セクションの下）に「プリセット別」セクションを追加。`data/presets.json` のプリセット一覧をチップで表示し、タップでそのプリセットで生成された画像をサムネイルグリッドで表示。

### §5.2 仕組み

`images.preset_id` が一致する画像を抽出。M3の `POST /api/save` で `preset_id` を受け取り済み（M4-Aで実装済み）。プリセットIDが記録されていない古い画像は表示されない。

### §5.3 API

| メソッド | パス | 用途 |
|---|---|---|
| GET | /api/gallery/by-preset/:presetId?limit={n} | プリセット別画像一覧（既定50件） |

## §6 セリフ表示・編集

### §6.1 表示

ビューアの情報オーバーレイ内にセリフ表示エリア。`images.caption` の値を表示。未設定時は「セリフなし」をグレーテキストで表示。

### §6.2 編集

セリフ表示エリアをタップ → テキストエリアに切り替わり編集可能。Enter or 保存ボタンで確定（`PUT /api/gallery/image/:hash/caption`）。

### §6.3 API

| メソッド | パス | 用途 |
|---|---|---|
| PUT | /api/gallery/image/:hash/caption | セリフ更新。body: `{ caption: "テキスト" }` |

## §7 ファイル構成（M4-B追加分）

```
src/
  components/
    ImageViewer.jsx             ← ビューア本装（スワイプ・情報オーバーレイ・横向き）
```

AlbumScreen.jsx から現行のインラインビューアを除去し、`ImageViewer` コンポーネントに委譲する。

## §8 テスト方針

### PG自己完結

| 項目 | 手順 | 合格基準 |
|---|---|---|
| スワイプ前後 | ビューアで左右スワイプ | 画像切替 |
| タップ前後 | 画面左端/右端タップ | 画像切替 |
| ×閉じる | ×ボタンタップ | ビューア閉じる |
| 情報オーバーレイ | 下部バータップ | プロンプト・パラメータ表示 |
| お気に入りトグル | ★タップ | DB反映・アイコン切替 |
| お気に入りフィルタ | ヘッダー★ON | お気に入りのみ表示 |
| 検索 | 🔍→テキスト入力→Enter | ヒット画像表示 |
| 検索フォルダラベル | 検索結果のサムネイル | フォルダ名が小さく表示 |
| プリセット別 | プリセットチップタップ | 該当画像表示 |
| セリフ表示 | ビューア→オーバーレイ | セリフ表示 or 「セリフなし」 |
| セリフ編集 | タップ→入力→保存 | DB反映 |
| 横向き | デバイスを横向き | オーバーレイが右サイドに移動 |
| build | npm run build | 警告なし |
| inspect | npm run inspect | ALL GREEN |

### 実機（発注者に依頼）

- Pixel 10でスワイプ操作の応答性
- 横向きでのレイアウト
- 検索速度（100枚以上で体感遅延がないか）
