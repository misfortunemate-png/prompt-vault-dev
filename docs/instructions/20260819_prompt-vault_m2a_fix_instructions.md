# M2-A 差し戻し: 生成結果のタブ切り替え保持

文書種別: 権威文書（差し戻し指示）
作成日: 2026-08-19 ／ PM: クリーデ ／ 発注者指示に基づく

## 問題

生成画面で出力した結果カードが、アルバムやテンプレートタブに遷移して戻ると消える。原因はGenerateScreenのアンマウントによるstate消失。

## 修正内容

1. **結果stateをApp.jsxに持ち上げる**: `results` と `setResults` をApp.jsxで管理し、GenerateScreenにpropsとして渡す。タブ切り替えでGenerateScreenがアンマウントされても結果が保持される

2. **保持件数の上限**: 既定5件。新しい結果が追加されたとき上限を超えた古いものから削除する

3. **設定画面に「結果保持件数」を追加**: 1〜100の数値入力。settings.jsonに `generation.maxResults` として保存。既定5

4. **リセット条件**: サーバー再起動またはブラウザリロードで結果は消える（localStorageに保存しない）

## テスト

- 生成→アルバムタブ→生成タブに戻る→結果カードが残っていること
- 上限を超えた場合、古い結果から消えること
- リロードで結果が消えること
