# prompt-vault ランダムサイズ生成 実装指示書

文書種別: 権威文書

作成日: 2026-09-01 ／ PM: クリーデ

## 背景

現在の生成設定は固定サイズ（832×1216・縦）のみ。縦・横・正方の3種類からランダムで選ぶ機能を追加する。

## 作業範囲

### 対象リポジトリ

- prompt-vault-dev（フロントUI）
- ai-family-foundation（Worker/DO — 必要な場合のみ）

### 追加する機能

生成設定UIに「ランダムサイズ」チェックボックスを追加する。ONの場合、生成リクエストごとに以下の3種類からランダムで1つを選択してwidth/heightに適用する。

| 名前 | width | height | 比率 |
|---|---|---|---|
| 縦 | 832 | 1216 | ≒2:3 |
| 横 | 1216 | 832 | ≒3:2 |
| 正方 | 1024 | 1024 | 1:1 |

いずれもNovelAI Opus無料圏（≤1MP）以内。

### チェックボックスOFFの場合

従来通り設定画面のwidth/height固定値を使う。既存の動作を変えない。

## 実装方針

サイズのランダム選択は**生成APIを呼ぶ直前**に行う。選択結果（どのサイズが選ばれたか）は生成結果のメタデータに残る（pv_imagesのwidth/heightに反映済みのはず）。

実装箇所がフロント側だけで完結するか、DO側の変更も必要かは、現在の生成フロー（フロントがwidth/heightをAPIに渡すのか、DOがsettingsから読むのか）に依存する。調査の上で判断し、報告に含めること。

## テスト

1. チェックボックスON → 3回生成 → 少なくとも2種類のサイズが出ること（確率的に3回全て同じサイズになる確率は1/9）
2. チェックボックスOFF → 設定画面のwidth/height固定値で生成されること
3. 生成された画像のpv_imagesレコードにwidth/heightが正しく記録されること

## 禁止事項

- 既存の固定サイズ生成の動作を変えない
- 3種類のサイズ定義をハードコードする（設定可能にする必要はない）
