## 変更内容

### #1 ビューアからカード登録

ImageViewer.jsxの情報オーバーレイ内、プロンプト表示セクションに**「📋 カードに登録」ボタン**を追加する。

**操作フロー:**
1. ビューアで画像を開く → 情報オーバーレイを展開 → プロンプトが表示される
2. 「📋 カードに登録」ボタンをタップ
3. ダイアログが開く:
   - **スロット選択**: プルダウン（既存スロット一覧＋「＋新規スロット」）
   - 「＋新規スロット」選択時: スロット名入力欄が表示
   - **カード名**: テキスト入力（既定: ファイル名からseed部分を除いた部分、または空欄）
   - **正プロンプト**: テキストエリア（画像のpromptで事前入力。編集可）
   - **負プロンプト**: テキストエリア（画像のnegativeで事前入力。編集可）
4. 「登録」ボタンで `POST /api/cards/card` を呼んでカード作成
5. 新規スロットの場合は先に `POST /api/cards/slot` でスロット作成してからカード作成
6. 成功 → トースト「カードを登録しました」→ ダイアログ閉じる

**API**: 既存の `/api/cards/slot` と `/api/cards/card` を使う。新規APIは不要。

**スロット一覧の取得**: `GET /api/cards` から取得。ImageViewerのpropsとして渡すか、ダイアログオープン時にfetchする。

### #2 セリフ（caption）表示バグ修正

M5完了報告の既知の残課題。原因を調査し修正すること。

調査ポイント:

- setDetail後にcaptionが保持されているか
- 編集モードの切り替え（タップ→テキストエリア→保存→テキスト表示）が正しく動くか

### #3 画像の削除

ビューアの情報オーバーレイに**「🗑 削除」ボタン**を追加する。

**操作フロー:**
1. ビューアで画像を開く → 情報オーバーレイを展開
2. 「🗑 削除」ボタンをタップ
3. 確認ダイアログ:「この画像を削除しますか？（元に戻せません）」
4. 確認 → `DELETE /api/gallery/image/:hash` を呼び出し
5. サーバー側処理:
   - VAULT_ROOTからファイルを削除
   - DBからレコードを削除
   - `data/thumbs/{hash}.webp` サムネイルを削除
6. 成功 → トースト「画像を削除しました」→ ビューアが次の画像に移動（最後の1枚なら閉じる）
7. 閉じた後、AlbumScreenのグリッドから削除された画像が消えている

**API:**

| メソッド | パス | 用途 |
|---|---|---|
| DELETE | /api/gallery/image/:hash | 画像削除（FS＋DB＋サムネイル） |

**db.jsにヘルパー追加**: `deleteImage(hash)` — DBレコード削除＋rel_pathを返す（FS削除用）
