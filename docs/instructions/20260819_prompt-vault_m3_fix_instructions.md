## 変更内容

### 1. GenerateScreen.jsx — スロット管理UIを追加

各スロットのプルダウン行に以下を直接配置する（三点リーダメニューではなく、すべてボタンとして見えている状態）:

```
[☰] [プルダウン: カード選択] [✏️] [F☐] [N☐] [×]
```

- **☰**: 並替え（上下ボタンまたはドラッグ）。モバイルではHTML5 Drag APIが動かないため**上下ボタン（▲▼）を推奨**
- **プルダウン**: カード選択（既存）
- **✏️**: インラインカード編集（既存）
- **F**: useAsFolderチェックボックス。ラベル「F」で省スペース化
- **N**: useInFilenameチェックボックス。ラベル「N」で省スペース化
- **×**: スロット削除ボタン。タップで確認ダイアログ（配下カードがある場合は警告）

スロットプルダウン群の下に:

```
[＋ スロット追加]
```

- タップ → スロット名入力ダイアログ → 追加 → プルダウン群に即時反映

F/Nチェック変更・並替え・追加・削除はそれぞれ対応するAPIを呼び出し（PUT /api/cards/slot/:id 等）、画面を即時更新する。

### 2. TemplateCardList.jsx — スロット管理UIを簡素化

スロット一覧から以下を**削除**する（生成画面に移管済みのため）:
- ドラッグハンドル（☰）
- パス設定（F/Nチェック）
- 削除ボタン
- 三点リーダメニュー（⋯）全体

スロット一覧は**カード一覧への導線**としてシンプルに残す:
- 各行: スロット名 + カード件数。タップでカード一覧へ
- スロット追加ボタン（テンプレートタブ側にも残す。どちらからでも追加可能にする）
- スロット改名（長押しまたは行内の改名ボタン。テンプレートタブでのみ改名可能とする）

## テスト

### PG自己完結

| 項目 | 手順 | 合格基準 |
|---|---|---|
| 生成画面スロット追加 | ＋スロット追加→名前入力 | プルダウン群に新スロット追加 |
| 生成画面スロット削除 | ×ボタン | 確認後に削除・プルダウン群から消える |
| 生成画面F/Nチェック | F/Nチェック変更→保存→アルバム | フォルダ/ファイル名が変更に従う |
| 生成画面並替え | ▲▼でスロット順変更 | プルダウン群の表示順が変わる |
| テンプレートタブ簡素化 | テンプレートタブのスロット一覧 | ドラッグ/F/N/削除/⋯なし。スロット名+件数のみ。タップでカード一覧 |
| テンプレートタブスロット改名 | スロット改名操作 | 改名が生成画面にも反映 |
| build | npm run build | 警告なし |
| inspect | npm run inspect | ALL GREEN |
