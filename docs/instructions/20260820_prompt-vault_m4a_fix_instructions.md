## 変更内容

### 1. フォルダ表示モード切替

フォルダツリーセクションのヘッダー（「フォルダ」ラベルの横）に表示モード切替トグルを配置。

2つのモード:

**一覧モード（現行）**: フォルダアイコン＋名前＋枚数のテキスト行。コンパクト。

**アイコンモード（新規）**: フォルダごとにカード形式で表示。各カードにフォルダ名＋枚数＋配下画像のサムネイルプレビュー（最大4枚）を含む。プレビューは2×2グリッドで小さく並べ、フォルダの中身を一目で把握できるようにする。

トグルUI: アイコン2つ並べたボタン（☰ 一覧 / ▦ アイコン）。選択中のモードをハイライト。既定はアイコンモード（中身が見えるほうが初見で便利）。選択はlocalStorageではなくReact state保持（セッション内のみ）。

### 2. フォルダプレビューAPI

`GET /api/gallery` のレスポンスに各フォルダの代表サムネイル（最大4件のhash）を追加する。

現行:
```json
{
  "tree": [
    { "name": "キャラA", "path": "キャラA", "imageCount": 15, "children": [] }
  ]
}
```

改訂:
```json
{
  "tree": [
    {
      "name": "キャラA",
      "path": "キャラA",
      "imageCount": 15,
      "children": [],
      "previewHashes": ["a1b2c3d4e5f6g7h8", "i9j0k1l2m3n4o5p6", ...]
    }
  ]
}
```

`previewHashes`: そのフォルダ内の画像から最新4件のハッシュ。DBから `folder` で絞り込み、`created_at DESC` で上位4件を取得。0枚のフォルダは空配列。

### 3. アイコンモードのレイアウト

```
┌─────────────────────────┐
│ ┌──────┬──────┐         │
│ │ thumb│ thumb│  キャラA │
│ ├──────┼──────┤  15枚   │
│ │ thumb│ thumb│         │
│ └──────┴──────┘         │
└─────────────────────────┘
```

- カードは横幅100%（モバイル）。カード内左に2×2サムネイルグリッド（各60×60px程度）、右にフォルダ名＋枚数
- PC幅ではカードを2列に並べても良い（レスポンシブ）
- 4枚未満の場合は空スロットをプレースホルダーで埋める
- カードタップ → そのフォルダへ遷移（現行と同じ動線）

## テスト

| 項目 | 手順 | 合格基準 |
|---|---|---|
| アイコンモード | アルバムタブ→フォルダセクション | フォルダカードにサムネイルプレビュー4枚表示 |

| gallery API | GET /api/gallery | previewHashesが各フォルダに含まれる |
| build | npm run build | 警告なし |
| inspect | npm run inspect | ALL GREEN |
